# Donatium

Let your devices do jobs when they are idle

## Supported operating systems

- Bluefin Dakotaraptor(or any other atomic distro)
- macOS

## Services

These only include services that are meaningfully contributive to a network by

- distributed compute
- automated scraping
- bandwidth sharing
- AI inference

but not by

- displaying ads
- maliciously hijacking user credentials
- performing destructive actions without user consent
